# 快速开始

## 三种打开方式

### 1. 直接访问线上版本

打开 <https://aaasjc.github.io/picmint/>。不需要注册，也没有任何文件会被上传。

### 2. 下载后本地双击

从 Releases 下载 ZIP，解压后双击 `index.html`。

> 某些浏览器在 `file://` 协议下会限制 Canvas 编码（尤其是 AVIF），遇到"无法编码"的报错时请改用下面的方式。

### 3. 本地服务器（推荐开发时使用）

```bash
git clone https://github.com/aaasjc/picmint.git
cd picmint
npm start
```

终端会输出 `http://127.0.0.1:4173`。换端口：

```bash
PORT=8080 npm start
```

这里用到的 `scripts/serve.mjs` 是一个 90 行的零依赖静态服务器，只做三件事：解析路径、防目录穿越、设置 MIME。

## 处理一张图片

1. 打开 `studio.html`（主页点「打开工坊」）。
2. 把图片拖进窗口，或按 `Ctrl/⌘ + O` 选择文件。
3. 右侧设置输出参数（默认 WebP，质量 82，不缩放）。
4. 点右上角「开始处理」，或直接按 `Enter`。
5. 处理完成后点「下载」，或在顶部点「打包下载」获取 ZIP。

左侧队列会实时显示 `原始体积 → 输出体积` 与节省比例。绿色代表变小，橙色代表变大。

## 参数怎么选

### 格式

| 格式 | 适合 | 注意 |
| --- | --- | --- |
| **WebP** | 默认选择，网页配图、文章插图 | 兼容性覆盖所有现代浏览器 |
| **AVIF** | 追求极限体积、可控的发布环境 | 编码较慢，旧浏览器不可用 |
| **JPEG** | 需要发给别人、导入老软件 | 不支持透明，透明区域会填白 |
| **PNG** | 图标、需要透明的截图、文字图 | 体积最大，质量滑块无效 |

### 质量

- **90–100**：几乎无损，体积增长快，只在需要印刷或二次编辑时使用。
- **78–85**：默认区间，绝大多数照片肉眼无差别。
- **60–75**：社交媒体、缩略图，能明显看到细节损失但体积更小。
- **30–59**：只适合纯色块或极低带宽场景。

### 最大边

只填一个数字，另一侧按比例推算。常用值：

- `2560` — 2K 屏截图、桌面壁纸
- `1920` — 1080p 展示、网页首图
- `1280` — 文章正文配图、邮件
- `800` — 缩略图、列表封面

填 `0` 或留空表示保持原尺寸。**不会放大**：小于设定值的图片保持原样。

### 截图美化

打开后输出统一为 PNG（避免文字边缘出现 JPEG 振铃），参数含义：

- **留白**：图片四周的渐变边距，8% 适合大多数截图，0% 只做圆角。
- **圆角**：20px 接近 macOS 窗口的视觉习惯，48px 适合做封面。
- **水印**：底部居中的一行小字，留空则不绘制。

## 键盘操作

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl/⌘ + O` | 打开文件选择器 |
| `Enter` | 处理队列中的全部图片 |
| `Delete` / `Backspace` | 移除当前选中的图片 |
| `Tab` | 在队列项之间移动焦点，`Enter` 选中 |

## 常见问题

**Q：为什么压缩后反而变大了？**

两种常见情况：原图已经高度优化；或者把 JPEG 转成了 PNG（无损格式）。默认开启「输出大于原图时保留原图」，行内会标注"原图"。关掉这个开关可以强制输出。

**Q：一次能处理多少张？**

上限 128 张/批，单张 80 MB。真正的瓶颈是设备内存 —— 一张 8000×6000 的图解码后约占 190 MB 内存。处理大批量时建议分批。

**Q：AVIF 选项是灰的？**

当前浏览器没有提供 AVIF 编码器。Chrome 85+、Edge 121+、Safari 16.4+ 支持；Firefox 目前只支持解码不支持编码。不会自动降级成别的格式，避免你拿到与预期不符的文件。

**Q：transparent PNG 转 JPEG 后背景是黑的？**

不会。PicMint 在 JPEG 输出前会先用白色填充画布（JPEG 没有 alpha 通道）。如果你看到黑底，说明用的是别的工具。

**Q：处理到一半刷新页面会怎样？**

所有状态都在内存里，刷新即清空。这是刻意的设计：不写 `localStorage`，避免图片数据在磁盘上留下副本。

**Q：能处理 HEIC（iPhone 照片）吗？**

取决于浏览器。Safari 可以解码 HEIC，Chrome 一般不行。如果拖入后提示无法解码，请先在系统里导出为 JPEG。
